# Задача 1. 

I. Создать класс Person, который описывает человека. Функциональность класса обеспечить с использованием следующих членов:

1.       закрытое поле age (хранит возраст человека);

2.       открытое поле retirementAge (хранит пенсионный возраст);

3.       конструкторы без параметров и с параметрами;

4.       метод СheckAge, который проверяет его пенсионный статус (уже на пенсии или сколько лет осталось до пенсии).

II. Выполнить следующие изменения:
1.       поле retirementAge (хранит пенсионный возраст) сделать закрытым;

2.       доступ к статической переменной retirementAge опосредуется с помощью статического свойства RetirementAge с ограничением пенсионного возраста от 1 до 100 лет.

Ш. Модифицировать класс Person - определить статический метод CheckRetirementStatus(), который в качестве параметра принимает объект Person и проверяет его пенсионный статус.
